# Web 工作台

## 启动

在项目根目录使用 PowerShell：

```powershell
uv pip install --python "..\.venv\Scripts\python.exe" -r requirements.txt
.\scripts\start_workbench.ps1
```

需要 Node.js/npm。首次启动安装前端锁定依赖并构建；访问 http://127.0.0.1:8501。已构建时可使用 `-SkipBuild`。模型配置继续读取 `src/.env`，无需覆盖已有配置。`app.py` 仅保留旧 Streamlit 兼容入口，不是默认界面。

## 界面与流程

- 左侧为真实 Wiki 文件层级，文件名称没有来源悬浮提示。
- 场景入口统一放在左侧，包含模拟面试、文件浏览与知识图谱；顶部不再分段切换。切换文件或查看关联卡片不推进面试，也不丢失回答草稿。
- 文件详情只读：顶部展示基本信息、来源、Wiki 关联链接和反向链接卡片，点击卡片跳转至实际文件。不执行模型请求、不触发入库。
- 新建面试的简历和项目材料只用于面试，沿用“首题宽、之后按回答深入”的 Python 链路，不进入知识库。
- “拓展现有知识库”是独立入口：选择并上传即授权后台处理；弹窗自动关闭，右上角蓝白通知展示解析、分析、生成、整合发布与索引阶段。用户不需要选择排队或连接操作。
- 已有 Markdown Wiki 和索引机制保留；索引可以重建。未授权暂存资料不会在重启后自动建库。

## 运行边界

服务仅面向本机开发，默认监听 127.0.0.1。浏览器 Cookie 隔离面试与上传，修改请求校验来源与专用请求头；这些措施不等于公网身份认证。不要直接开放到公网。

面试会话保存在进程内，服务重启后不能恢复；Wiki、上传原件和建库授权/任务状态持久化。配置密钥不返回前端。授权建库与模拟面试会向配置的模型提供商发送相关文本，并可能产生费用。

当前不包含编辑器、公网登录和面试跨重启恢复。知识图谱与分阶段建库、补链的细则见 `knowledge-graph-workflows.md`。Markdown 禁止原始 HTML 执行，远程图片不自动加载。

## 验证

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -v
Push-Location frontend
npm.cmd run build
Pop-Location
```

离线测试和浏览器联调用假模型验证界面、授权与状态隔离，不证明真实模型出题质量或 Wiki 检索采用率。

专用上传已取消仅暂存模式。待执行步骤红色、进行中黄色、完成绿色；失败显示实际原因，索引失败不会被标为100%。关闭通知只隐藏，不取消任务。
