# 知识图谱、分阶段 Wiki 与新增文件补链

## 保持原框架

在现有 React + TypeScript / FastAPI / Python 工作台内增量更新。图谱使用 MIT 许可的 `react-force-graph-2d`，不复制 `llm_wiki` 的 GPL 实现，不迁移旧 Wiki，不引入 Milvus。

## 场景导航与图谱

顶部不再有分段切换。左侧栏切换模拟面试、文件浏览、来源资料和知识图谱；面试面板和图谱保持挂载，切换不丢失草稿、缩放和位置。

图谱节点与左侧安全文件目录一致，包含未发布普通 Markdown、实体、概念、原始资料、摘要、参考题、综合和根目录导航文件。隐藏草稿、私有目录、隐藏文件及越界路径不在目录内；超大文件只展示节点，不解析关系。

链接解析支持来源引用、Wiki ID、明确相对路径、别名、锚点和显示别名。无法消除歧义的短名称不创建关系。同一对节点的引用/反向引用合并为一条边，保留方向和关系类别。图谱与详情卡片共用解析器，避免两处结果不同。

鼠标悬停节点，仅显示自身、直接关联节点和直接连线；移开恢复，不改变力布局。 下拉框与悬停状态独立：自动模式下使用临时悬停筛选；选择具体文件后固定显示其邻域；选择“查看全部节点（固定）”后保持全图。鼠标移动、移出、数据轮询及文件详情往返均不解除固定选择；切换选择或重置才改变模式，重置恢复自动模式。点击进入只读详情，返回保留相机。支持平移、缩放、拖动、重置、分类颜色及键盘定位节点。

## 分阶段生成

专用拓展弹窗内选择并上传即授权运行核心阶段，普通面试附件不受此规则影响：

1. 解析与分段分析，提取来源事实、概念、实体。
2. 统一规划稳定页面 ID、旧页复用、明确别名和链接。
3. 独立分段/页面通过 asyncio + to_thread 并发处理，每批并发上限 3。
4. 统一校验证据编号、来源引句与链接目标；加锁、版本校验和事务发布。
5. 写入 `sources/` 原始快照与来源摘要、`concepts/`、`entities/`，维护最小 index/log，并更新 Embedding 索引。
6. 停止，显示结果和覆盖提示；未必每类都有页面，没有依据不凑类型。

后续通过“知识任务与补链”单独授权：

- 第二阶段：按已有文件分组整理 overview；保留手写内容与可重建的受控导航区块，不产生新技术事实。
- 第三阶段：规划并并发生成 question/synthesis，保留来源、旧内容和争议。需先完成第二阶段，不自动继续。

原有 legacy 生成入口和 `summaries/` 来源摘要仍可运行，旧页面不迁移。已完成的旧资料可以在任务窗口明确点击“按新规则补齐核心知识”，或重新添加同一原件并启动；只会在授权后创建新版核心任务，旧发布页保留。页面生成失败不发布半批。基础 index/log 由程序维护，不额外调用模型。

## 复制文件后的补链

工作台每约 2.5 秒请求一次活动状态，本地扫描对新增文件做至少 2 秒内容稳定判定，不是文件复制瞬间触发的操作系统 watcher。首次安装建立已有文件基线；之后新增记录持久化，离线复制的文件在再次打开工作台后识别。系统发布的路径不重复弹出提醒。

1. 提醒“发现新增 Wiki 文件”。检测不调用模型、不修改文件。
2. 用户点击“分析并生成补链方案”。先关键词/名称候选召回；现有向量索引可用时，对明确授权的新增文本做 Embedding 召回，再由 LLM 判断。
3. 每条方案展示起点、目标、类别、理由、双方逐字引句和拟追加 Wiki 链接。程序验证目标、双端证据与快照版本，去重。允许零建议。
4. 用户选择建议并确认后，只向新增文件追加受控链接区块；保留原字节前缀（包括 BOM 和原换行），不改写旧文件正文，不添加 approved 标志。
5. 更新 log，刷新图谱与受影响的已发布页索引。反向关系动态计算，不额外改写旧文件。

取消方案不修改文件。模型或服务中断不会自动重新运行补链/后续阶段；需明确重新启动。任一关联文件变化则拒绝旧方案。索引失败与知识保存成功分别展示，不能冒充检索就绪。

## 范围与限制

- 本机单实例服务，不包含公网身份认证；浏览器 Cookie 隔离用户任务，修改操作继续校验请求来源。
- 面试会话仍是进程内状态，重启会丢失。
- 图谱表达实际文件引用，不是外部事实数据库或自动推断全库语义关系。
- 当前最多 300 张已发布知识页、每批最多 7 张模型知识页加来源摘要，预览最多 1000 个安全文件。索引不可用时补链使用关键词候选，页面明确展示召回方式。
- 根目录普通 Markdown 以及受支持知识目录的 Markdown 可以检测；私有/隐藏目录不能通过补链访问。
- 新阶段生成按用户授权可自动发布；“补链方案”额外需要写入确认。补链本身不是发布审批。

## 验证

离线测试使用临时目录与假 LLM/Embedding，不读取真实简历，不请求真实模型。浏览器测试验证真实鼠标悬停、关系过滤、位置保留、草稿保留、阶段授权及复制-分析-确认三条边界。真实模型的实体提取质量、关系判断质量与费用需要另行授权验收。

## 上传处理通知（当前默认页面）

选择文件后立即关闭拓展弹窗，并在右上角显示蓝白进度通知。上传、解析、分段分析、页面规划/并发生成、整合发布和索引计数来自真实任务状态，不依据时间虚增百分比。总体百分比是五个阶段的完成比例（分析/生成阶段细分为分段/页面计数），不是模型 token 或预计耗时比例。待执行红色、进行中黄色、完成绿色，失败显示错误；只有索引成功才达到100%。

隐藏通知不取消任务；刷新时恢复活动任务并保持完成结果可见。专用上传调用新 `/api/knowledge/upload`，旧 `/stage` 仅作为兼容内部接口保留，不是默认界面流程。复制文件补链的模型分析与写入确认、可选导航/深化阶段的授权边界均保持不变。

### 紧凑进度入口

处理通知默认收起为拓展按钮正下方的圆环和整体百分比。鼠标悬停展开详细卡片；可将鼠标移入卡片查看或重试，离开后收起。点击支持触屏，键盘聚焦/Enter可展开，Escape收起并返回入口。收起不取消任务。多文件进度按各文件阶段完成度取平均；只要有文件尚未就绪，整体不会显示100%。

## 来源节点去重

同一资料的生成来源摘要与原文快照，在资料列表和图谱中统一显示为摘要节点。只有已发布摘要、唯一匹配的生成快照路径与身份后缀才投影合并，不按标题猜测；未配对原文和普通笔记仍显示。来源引用、正文Wiki链接和关系元数据均先解析再投影到规范节点，去重并删除投影产生的自连接。

底层原始文件、来源快照、证据定位和索引数据不改变。详情提供“查看原文快照 / 返回来源摘要”，关联卡片与图谱使用同一投影结果。
